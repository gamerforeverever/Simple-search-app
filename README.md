# [Simple Search](https//:simplesearch.netlify.app)

A simple, fast and privacy-friendly open-source search engine.

Simple Search is a lightweight search experience focused on simplicity, speed and clean design. No ads, no tracking, no unnecessary features just search.

## Features

Fast searching
Wikipedia integration
Mobile-friendly design
Works on desktop, tablet and phone
Dark & light mode
Adjustable font size
Saves user preferences
No ads
Privacy focused
Single-file version available

## Installation

### Option 1: use over web

1. go to [Simple Search Website](simplesearchs.netlify.app)
2. done
   
### Option 2: Download

1. Download the repository
2. Open `index.html`
3. Start searching

### Option 3: Host yourself

You can host Simple Search on:

GitHub Pages
Netlify
Cloudflare Pages
Any static web host

### Option 4: Over apk

You can build it yourself or download in releases

## Goals

The goal of Simple Search is to create:

  A clean alternative to ad-heavy search engines
  A beginner-friendly open-source project
  A fast search tool that respects users
